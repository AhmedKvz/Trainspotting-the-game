# NIGHTLIFE — Level 01: Underground Club

## Goal
Build one dense club that supports multiple roles and different access routes without an open-world city.

Approximate main footprint: **45m × 25m**.

## Main zones
- Street / queue
- Main entrance
- Security check
- Foyer / cloakroom
- Main bar
- Dance floor
- DJ booth
- VIP mezzanine
- Secondary bar
- Toilets
- Smoking area / terrace
- Backstage / green room
- Staff corridor
- Storage / technical
- Afterparty / service exit

## Public route
Street → Security → Foyer → Main Bar → Dance Floor → Smoking Area

## Staff route
Entrance → Staff Corridor → Bars → DJ Booth → Backstage → Service Exit

## VIP route
Entrance → VIP Access → VIP Mezzanine → Backstage → Private Exit

## Level-design rule
Every room must create gameplay, information, access, social opportunity or traversal value.

## Verticality
VIP should be elevated enough to overlook the dance floor. The player should be able to see aspirational spaces before they can access them.

## Landmarks
- DJ booth: strongest focal lighting
- Main bar: warm social anchor
- VIP: elevated premium visual language
- Smoking area: cooler decompression space
- Backstage: controlled-access story space

## Crowd volumes
- CV_DanceFloor
- CV_BarMain
- CV_BarSecondary
- CV_Smoking
- CV_Foyer
- CV_VIP

Each volume should expose desired density, capacity, social weight, music interest and drink demand.

## Blockout acceptance criteria
- Player can understand major destinations without minimap.
- Dance floor and DJ booth are visible from the main circulation.
- Staff routes offer meaningful shortcuts.
- VIP/backstage feel like visible progression.
- No traversal segment is dead space.
